# Sami Al-Najadat — Portfolio

Personal portfolio of **Sami Ismaeel Al-Najadat**, Full Stack Web Developer (PHP · Laravel · Yii2 · Node.js · NestJS · React · Next.js · MySQL · PostgreSQL).

🔗 **Live:** https://sami-al-njadat.github.io/project2/

## Features

- Bilingual: English / Arabic (RTL) with one click — the choice is remembered
- Animated hero, particle background, scroll reveal and counters
- Skills, experience & education timeline
- Filterable projects grid linked to GitHub repositories
- Contact cards (email, phone, WhatsApp, Telegram, LinkedIn) and a message form that opens Email or WhatsApp
- Fully responsive, no build step — plain HTML, CSS and JavaScript

## Structure

```
index.html            page markup
assets/css/style.css  styles
assets/js/main.js     content (EN/AR text, skills, projects) and interactions
assets/img/           photo, logo and education logos
```

To add a project or edit any text, change the `PROJECTS` / `I18N` objects at the top of `assets/js/main.js`.
